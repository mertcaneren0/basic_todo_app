# Basic To-Do App

A simple to-do list in plain JavaScript that keeps your tasks in the browser's Local Storage.

## What it demonstrates
- DOM manipulation: creating and removing list items
- Event handling and event delegation
- Saving and loading data with `localStorage`

## Features
- Add a new task
- Delete a single task (with a confirm dialog)
- Delete all tasks at once
- Tasks stay after a page refresh

## Tech
- HTML, CSS, vanilla JavaScript
- Bootstrap 4 and Font Awesome (from CDN)

## How to run
Open `index.html` in your browser. No build step needed.
